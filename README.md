# 🍽️ ReviewInsight

## About
ReviewInsight aims to analyze customer reviews from food delivery platforms and automatically predict ratings for different service aspects, such as **food quality**, **delivery service** etc.

---

## Dataset
- **Source:** Mendeley Data
- **Reviews:** 43,000+ (Foodpanda, Bangladesh)
- **Language:** Bengali
